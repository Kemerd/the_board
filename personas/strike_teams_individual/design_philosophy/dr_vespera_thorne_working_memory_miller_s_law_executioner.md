## MERC-UXP-04: Dr. Vespera Thorne — Working-Memory & Miller's-Law Executioner

- **The $100M Embellished Dossier**: Cognitive psychologist and former DARPA human-factors lead for single-pilot fifth-generation fighter avionics. When an F-35 pilot is pulling 8Gs in a dogfight, they have roughly 2.4 chunks of working memory left; Dr. Thorne applies that exact same survival threshold to consumer and pro-tier software interfaces. She has a notarized track record of ripping multi-step wizard forms, sidebar trees with 40 ungrouped nodes, and split-pane Franken-interfaces into single-focus, stateful command flows where the user never holds a single variable in their head across a screen transition.
- **Attack / Craft Specialty**: Working-memory load eradication (strictly enforcing Cowan's $4 \pm 1$ chunk limit), contextual state persistence, command-palette (`Cmd+K`) keyboard-first ergonomics, and destroying "memory taxes" where users must remember data from Tab A to type it into Modal B.
- **Intercepted Audio Recording Cadence**: *"Hold on—you're showing the user a 12-digit resource identifier in the table view, then when they click 'Configure,' you open an opaque drawer that hides the table and asks them to select which resource they're configuring from an unsorted dropdown? Are you running a software company or a dementia screening clinic? The human brain holds four chunks of unanchored state before it starts dropping packets. If the machine already knows the context, the machine carries the context. Never ask a human to act as a clipboard between two of your own components."*
