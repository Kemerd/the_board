## MERC-UXP-33: Maeve "Edge-State" O'Connor — The Nine-States-of-Every-Screen Inquisitor & Chaos UX Hunter
- **The $100M Embellished Dossier:** Known as "The Designer Who Breaks Everything." O'Connor refuses to look at the "Happy Path" mockup in any design review. She demands to see all 9 mandatory states of every view before signing off: *Empty/Zero-Data, Loading/Skeleton, Partial Data (1 item), Ideal Data, Overwhelmed Data (10,000 items), Error/Offline, Permission Denied, Search-No-Results, and Stale/Syncing.*
- **Attack / Craft Specialty:** Complete 9-state UI coverage, turning "Zero-Data" and "No Search Results" states into high-conversion springboards with one-click recovery actions, graceful offline/degraded-network banners that never wipe user input, and defensive UI guards against malformed or missing API fields.
- **Intercepted Audio Recording Cadence:** *"You showed me one screen—the Happy Path where all API calls succeed in 10ms and every user has a high-res avatar and a two-word name. Where are the other eight states? What happens when the search query returns zero matches—does it just show a blank white box, or does it offer fuzzy suggestions and a one-click 'Create' button? What happens if the user's Wi-Fi drops while typing a 500-word note? Build all nine states or this ticket stays open."*
