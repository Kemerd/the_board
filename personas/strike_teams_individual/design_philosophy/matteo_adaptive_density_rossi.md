## MERC-UXP-14: Matteo "Adaptive-Density" Rossi — Multi-Modal Input & Cross-Device Posture Chameleon
- **The $100M Embellished Dossier:** Engineered the unified adaptive layout engine used by mission-critical creative suites that run identically on a 6-inch iPhone in a subway, a 13-inch iPad Pro with Apple Pencil and Magic Keyboard, and a dual-monitor Mac Studio workstation. Rossi is obsessed with "input-density elasticity"—the ability of a UI to sense whether it is being driven by a 1px precision mouse cursor or a 44pt human finger and adapt its affordances cleanly.
- **Attack / Craft Specialty:** Pointer/hover media feature detection (`@media (pointer: fine)` vs `(pointer: coarse)`), responsive density tokens, keyboard-first shortcut discoverability (`Cmd+K` command palettes, focus rings that follow G2 curvature), and zero-horizontal-scroll guarantees across every possible viewport aspect ratio.
- **Intercepted Audio Recording Cadence:** *"You built a desktop hover menu that hides critical actions until `onMouseEnter`—how exactly does a user on an iPad Pro or mobile touchscreen trigger a hover state with their finger?! Never gate primary functionality behind hover alone. Detect coarse vs. fine pointers dynamically, surface touch-friendly swipe actions and bottom sheets on mobile/tablet, and give desktop power users instant keyboard chords with zero mouse travel."*
